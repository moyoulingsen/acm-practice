# 模拟与计数

## ABC448 B - Pepper Addiction

链接：https://atcoder.jp/contests/abc448/tasks/abc448_b

### 题意

有 `M` 种胡椒，第 `j` 种有 `C_j` 克。第 `i` 道菜只能使用第 `A_i` 种胡椒，最多使用 `B_i` 克。问最多一共能使用多少克胡椒。

### 思路

按胡椒种类分桶。设 `need[x]` 表示所有需要第 `x` 种胡椒的菜最多一共需要多少克，那么第 `x` 种胡椒实际最多贡献：

```text
min(C_x, need[x])
```

所有种类相加就是答案。

### 复杂度

时间复杂度：`O(N+M)`  
空间复杂度：`O(M)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;

    vector<long long> C(M + 1), need(M + 1);
    for (int i = 1; i <= M; i++) cin >> C[i];

    for (int i = 0; i < N; i++) {
        int A;
        long long B;
        cin >> A >> B;
        need[A] += B;
    }

    long long ans = 0;
    for (int i = 1; i <= M; i++) {
        ans += min(C[i], need[i]);
    }

    cout << ans << '\n';
    return 0;
}
```

## ABC448 C - Except and Min

链接：https://atcoder.jp/contests/abc448/tasks/abc448_c

### 题意

有 `N` 个球，第 `i` 个球上写着 `A_i`。每次询问会临时拿走至多 `K <= 5` 个指定球，问剩下的球中最小的数字是多少。

### 思路

每次最多只会拿走 5 个球，所以全局最小的前 6 个球里一定至少有一个没被拿走。把 `(A_i, i)` 排序，只保留前 6 个候选。每次询问从这 6 个里找第一个没被拿走的即可。

### 复杂度

时间复杂度：`O(N log N + Q)`，因为每次询问只检查常数个候选  
空间复杂度：`O(N)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;

    vector<pair<long long, int>> a(N);
    for (int i = 0; i < N; i++) {
        cin >> a[i].first;
        a[i].second = i + 1;
    }

    sort(a.begin(), a.end());

    vector<pair<long long, int>> cand;
    for (int i = 0; i < 6; i++) cand.push_back(a[i]);

    while (Q--) {
        int K;
        cin >> K;

        vector<int> removed(K);
        for (int i = 0; i < K; i++) cin >> removed[i];

        for (auto [val, idx] : cand) {
            bool gone = false;
            for (int x : removed) {
                if (x == idx) gone = true;
            }
            if (!gone) {
                cout << val << '\n';
                break;
            }
        }
    }

    return 0;
}
```

## ABC450 C - Puddles

链接：https://atcoder.jp/contests/abc450/tasks/abc450_c

### 题意

给定 `H x W` 的黑白网格，`.` 是白格，`#` 是黑格。统计有多少个白色四连通块不接触网格边界。

### 思路

对每个未访问过的白格做 BFS/DFS，遍历整个白色连通块。遍历时记录这个连通块是否碰到了边界。如果没有碰到边界，答案加一。

### 复杂度

时间复杂度：`O(HW)`  
空间复杂度：`O(HW)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int H, W;
    cin >> H >> W;

    vector<string> S(H);
    for (auto &row : S) cin >> row;

    vector<vector<int>> vis(H, vector<int>(W));
    int dr[4] = {1, -1, 0, 0};
    int dc[4] = {0, 0, 1, -1};
    int ans = 0;

    for (int si = 0; si < H; si++) {
        for (int sj = 0; sj < W; sj++) {
            if (S[si][sj] != '.' || vis[si][sj]) continue;

            bool touch = false;
            queue<pair<int, int>> q;
            q.push({si, sj});
            vis[si][sj] = 1;

            while (!q.empty()) {
                auto [r, c] = q.front();
                q.pop();

                if (r == 0 || r == H - 1 || c == 0 || c == W - 1) {
                    touch = true;
                }

                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];
                    if (nr < 0 || nr >= H || nc < 0 || nc >= W) continue;
                    if (S[nr][nc] != '.' || vis[nr][nc]) continue;
                    vis[nr][nc] = 1;
                    q.push({nr, nc});
                }
            }

            if (!touch) ans++;
        }
    }

    cout << ans << '\n';
    return 0;
}
```
