# 字符串与滑动窗口

## ABC449 C - Comfortable Distance

链接：https://atcoder.jp/contests/abc449/tasks/abc449_c

### 题意

给定长度为 `N` 的小写字符串 `S`，以及整数 `L, R`。求满足下面条件的 `(i, j)` 数量：

```text
1 <= i <= j <= N
S_i = S_j
L <= j - i <= R
```

### 思路

固定右端点 `j`，左端点 `i` 必须在区间：

```text
j - R <= i <= j - L
```

并且 `S_i = S_j`。

从左到右扫描 `j`，维护这个合法区间内每个字符出现了多少次。每到一个 `j`：

1. 把 `j-L` 位置加入窗口；
2. 把 `j-(R+1)` 位置移出窗口；
3. 当前贡献就是窗口内字符 `S_j` 的数量。

### 复杂度

时间复杂度：`O(N)`  
空间复杂度：`O(26)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, L, R;
    string S;
    cin >> N >> L >> R >> S;

    vector<int> cnt(26);
    long long ans = 0;

    for (int j = 0; j < N; j++) {
        if (j >= L) cnt[S[j - L] - 'a']++;
        if (j >= R + 1) cnt[S[j - R - 1] - 'a']--;
        ans += cnt[S[j] - 'a'];
    }

    cout << ans << '\n';
    return 0;
}
```

## ABC450 E - Fibonacci String

链接：https://atcoder.jp/contests/abc450/tasks/abc450_e

### 题意

给定两个字符串 `X, Y`，定义：

```text
S_1 = X
S_2 = Y
S_i = S_{i-1} + S_{i-2}
```

每次询问给出 `L, R, C`，求 `S_{10^18}` 的第 `L` 到第 `R` 个字符中，字符 `C` 出现了多少次。

### 思路

`S_i` 的长度按斐波那契增长，所以只要找到最小的 `K`，使 `|S_K| >= maxR`，之后所有询问都可以在 `S_K` 上处理。

预处理：

- `len[k]`：`S_k` 的长度；
- `total[k][c]`：`S_k` 中字符 `c` 的出现次数；
- `X` 和 `Y` 的前缀字符计数。

每次求区间答案时，转成：

```text
count_prefix(R, C) - count_prefix(L-1, C)
```

`count_prefix(n, C)` 用 `S_k = S_{k-1} + S_{k-2}` 递归拆：

- 如果 `n <= len[k-1]`，继续看 `S_{k-1}`；
- 否则先加上整个 `S_{k-1}` 中 `C` 的数量，再去 `S_{k-2}` 里找剩下的前缀。

### 复杂度

预处理复杂度：`O(26(|X|+|Y|+K))`  
单次询问复杂度：`O(K)`，其中 `K` 约为 `O(log maxR)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;
const int64 INF = (int64)4e18;

struct Query {
    int64 L, R;
    char C;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string X, Y;
    cin >> X >> Y;

    int Q;
    cin >> Q;

    vector<Query> queries(Q);
    int64 maxR = 0;
    for (auto &q : queries) {
        cin >> q.L >> q.R >> q.C;
        maxR = max(maxR, q.R);
    }

    int nx = X.size();
    int ny = Y.size();

    vector<array<int64, 26>> prefX(nx + 1), prefY(ny + 1);
    prefX[0].fill(0);
    prefY[0].fill(0);

    for (int i = 0; i < nx; i++) {
        prefX[i + 1] = prefX[i];
        prefX[i + 1][X[i] - 'a']++;
    }
    for (int i = 0; i < ny; i++) {
        prefY[i + 1] = prefY[i];
        prefY[i + 1][Y[i] - 'a']++;
    }

    vector<int64> len(3);
    len[1] = nx;
    len[2] = ny;

    int K = 2;
    while (len[K] < maxR) {
        int64 nxt = len[K] + len[K - 1];
        len.push_back(min(nxt, INF));
        K++;
    }

    vector<array<int64, 26>> total(K + 1);
    total[1] = prefX[nx];
    total[2] = prefY[ny];

    for (int k = 3; k <= K; k++) {
        for (int c = 0; c < 26; c++) {
            total[k][c] = total[k - 1][c] + total[k - 2][c];
        }
    }

    auto count_prefix = [&](int64 n, char ch) {
        int c = ch - 'a';
        int k = K;
        int64 ans = 0;

        while (n > 0) {
            if (k == 1) {
                ans += prefX[n][c];
                break;
            }
            if (k == 2) {
                ans += prefY[n][c];
                break;
            }

            if (n <= len[k - 1]) {
                k--;
            } else {
                ans += total[k - 1][c];
                n -= len[k - 1];
                k -= 2;
            }
        }

        return ans;
    };

    for (auto q : queries) {
        cout << count_prefix(q.R, q.C) - count_prefix(q.L - 1, q.C) << '\n';
    }

    return 0;
}
```
