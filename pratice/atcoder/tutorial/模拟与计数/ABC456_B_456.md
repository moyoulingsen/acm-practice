# ABC456 B - 456

## 网址

https://atcoder.jp/contests/abc456/tasks/abc456_b

## 题解

三个骰子各有 6 个面，总共有 `6^3 = 216` 种等概率结果。

枚举三个骰子分别掷出的面，把得到的三个数排序，若排序后为 `{4,5,6}`，则计入有利结果。答案为：

```text
cnt / 216
```

时间复杂度：`O(6^3)`。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<vector<int>> A(3, vector<int>(6));
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 6; j++) cin >> A[i][j];
    }

    int cnt = 0;
    for (int i = 0; i < 6; i++) {
        for (int j = 0; j < 6; j++) {
            for (int k = 0; k < 6; k++) {
                vector<int> v = {A[0][i], A[1][j], A[2][k]};
                sort(v.begin(), v.end());
                if (v == vector<int>{4, 5, 6}) cnt++;
            }
        }
    }

    cout << fixed << setprecision(10) << cnt / 216.0 << '\n';
    return 0;
}
```
