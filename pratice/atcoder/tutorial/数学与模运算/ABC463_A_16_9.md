# ABC463 A - 16:9

## 网址

https://atcoder.jp/contests/abc463/tasks/abc463_a

## 题解

判断比例 `X:Y` 是否等于 `16:9`。不要用小数除法，直接交叉相乘：

```text
X / Y = 16 / 9  <=>  9X = 16Y
```

因此只要判断 `9 * X == 16 * Y` 即可。

时间复杂度：`O(1)`。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long X, Y;
    cin >> X >> Y;

    cout << (9 * X == 16 * Y ? "Yes" : "No") << '\n';
    return 0;
}
```
