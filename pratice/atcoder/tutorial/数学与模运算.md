# 数学与模运算

## ABC448 E - Simple Division

链接：https://atcoder.jp/contests/abc448/tasks/abc448_e

### 题意

给定一个很大的十进制整数 `N` 的游程压缩形式：每段表示某个数字 `c_i` 连续出现 `l_i` 次。要求输出：

```text
floor(N / M) mod 10007
```

### 思路

只需求出：

```text
r = N mod (M * 10007)
```

然后答案就是：

```text
r / M
```

原因是设 `N = qM + s`，其中 `0 <= s < M`，那么：

```text
N mod (M * 10007) = (q mod 10007) * M + s
```

因此对这个余数整除 `M`，就得到 `q mod 10007`。

接下来要解决的是如何根据游程压缩快速构造 `N mod MOD`。如果当前值是 `cur`，后面追加 `l` 个数字 `c`，则：

```text
cur' = cur * 10^l + c * 111...111
```

其中 `111...111` 长度为 `l`。用倍增预处理 `10^(2^k)` 和长度为 `2^k` 的 repunit，即可 `O(log l)` 处理一段。

### 复杂度

时间复杂度：`O(K log max(l_i))`  
空间复杂度：`O(log max(l_i))`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int K;
    int64 M;
    cin >> K >> M;

    vector<int64> c(K), l(K);
    for (int i = 0; i < K; i++) {
        cin >> c[i] >> l[i];
    }

    int64 MOD = M * 10007LL;
    const int LOG = 31;

    vector<int64> pow10(LOG), rep(LOG);
    pow10[0] = 10 % MOD;
    rep[0] = 1 % MOD;

    for (int i = 1; i < LOG; i++) {
        pow10[i] = pow10[i - 1] * pow10[i - 1] % MOD;
        rep[i] = (rep[i - 1] * pow10[i - 1] + rep[i - 1]) % MOD;
    }

    auto calc = [&](int64 len) {
        int64 p = 1 % MOD;
        int64 r = 0;

        for (int i = 0; i < LOG; i++) {
            if ((len >> i) & 1LL) {
                r = (r * pow10[i] + rep[i]) % MOD;
                p = p * pow10[i] % MOD;
            }
        }

        return pair<int64, int64>(p, r);
    };

    int64 cur = 0;
    for (int i = 0; i < K; i++) {
        auto [p, r] = calc(l[i]);
        cur = (cur * p + c[i] * r) % MOD;
    }

    cout << cur / M << '\n';
    return 0;
}
```

## ABC449 D - Make Target 2

链接：https://atcoder.jp/contests/abc449/tasks/abc449_d

### 题意

平面格点 `(x, y)` 的颜色由 `max(|x|, |y|)` 决定：如果它是偶数则为黑色，否则为白色。给定矩形范围：

```text
L <= x <= R
D <= y <= U
```

求其中黑色格点数量。

### 思路

把点分成两类，避免重复统计。

第一类：`|x| > |y|`，此时最大值是 `|x|`，所以只枚举偶数 `x`，统计满足：

```text
-|x| < y < |x|
```

且在矩形内的 `y` 有多少个。

第二类：`|x| <= |y|`，此时最大值是 `|y|`，所以只枚举偶数 `y`，统计满足：

```text
-|y| <= x <= |y|
```

且在矩形内的 `x` 有多少个。

两类互不重叠，相加即可。

### 复杂度

时间复杂度：`O((R-L+1)+(U-D+1))`  
空间复杂度：`O(1)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll L, R, D, U;
    cin >> L >> R >> D >> U;

    ll ans = 0;

    for (ll x = L; x <= R; x++) {
        if (x % 2 != 0) continue;

        ll ax = llabs(x);
        ll low = max(D, -ax + 1);
        ll high = min(U, ax - 1);
        if (low <= high) ans += high - low + 1;
    }

    for (ll y = D; y <= U; y++) {
        if (y % 2 != 0) continue;

        ll ay = llabs(y);
        ll low = max(L, -ay);
        ll high = min(R, ay);
        if (low <= high) ans += high - low + 1;
    }

    cout << ans << '\n';
    return 0;
}
```

## ABC450 D - Minimize Range

链接：https://atcoder.jp/contests/abc450/tasks/abc450_d

### 题意

给定数组 `A` 和正整数 `K`。每次可以选择一个元素加上 `K`，操作任意次。求最终可能达到的最小 `max(A)-min(A)`。

### 思路

每个数对 `K` 取模的余数不会变。问题等价于在模 `K` 的圆环上，把所有余数放进一个尽可能短的连续区间。

如果把圆环上最大的空隙切开，那么剩下所有点所在的区间最短。所以答案是：

```text
K - 最大相邻余数间隔
```

注意相邻间隔包括首尾之间跨过 `K` 的环形间隔。

### 复杂度

时间复杂度：`O(N log N)`  
空间复杂度：`O(N)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    long long K;
    cin >> N >> K;

    vector<long long> r(N);
    for (int i = 0; i < N; i++) {
        long long x;
        cin >> x;
        r[i] = x % K;
    }

    sort(r.begin(), r.end());

    long long gap = r[0] + K - r.back();
    for (int i = 0; i + 1 < N; i++) {
        gap = max(gap, r[i + 1] - r[i]);
    }

    cout << K - gap << '\n';
    return 0;
}
```

## ABC449 G - Many Repunit Sum 2

链接：https://atcoder.jp/contests/abc449/tasks/abc449_g

### 题意

`d` 位 repunit 是十进制下由 `d` 个 `1` 组成的数。给定 `N, M`，求有多少个整数可以表示成 `N` 个 repunit 的和，其中每个 repunit 的位数都在 `[1, M]` 内，允许重复。答案对 `998244353` 取模。

### 思路

利用：

```text
R_d = (10^d - 1) / 9
```

把 `N` 个 repunit 的和转成 `N` 个 `10^0, 10^1, ..., 10^{M-1}` 的和的计数问题。

最后可以转化为统计非负整数数组：

```text
(A_0, A_1, ..., A_{M-1})
```

满足：

- `0 <= A_i <= 9`，其中 `0 <= i <= M-2`；
- `A_{M-1}` 无上界；
- `sum A_i <= N`；
- `sum A_i ≡ N (mod 9)`。

生成函数为：

```text
(1+x+...+x^9)^(M-1) / (1-x)
```

先求 `G(x)=(1+x+...+x^9)^(M-1)` 的前 `N` 项系数，再做前缀和表示除以 `(1-x)`。官方做法用微分方程递推系数。

### 复杂度

时间复杂度：`O(N)`，常数约为 10  
空间复杂度：`O(N)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const ll MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    ll M;
    cin >> N >> M;

    ll K = (M - 1) % MOD;

    vector<ll> inv(N + 1, 1);
    for (int i = 2; i <= N; i++) {
        inv[i] = MOD - (MOD / i) * inv[MOD % i] % MOD;
    }

    vector<ll> g(N + 1);
    g[0] = 1;

    for (int n = 0; n < N; n++) {
        ll rhs = 0;
        for (int j = 0; j <= 8 && j <= n; j++) {
            rhs = (rhs + 1LL * (j + 1) * g[n - j]) % MOD;
        }
        rhs = rhs * K % MOD;

        ll known = 0;
        for (int i = 1; i <= 9 && i <= n; i++) {
            known = (known + 1LL * (n - i + 1) * g[n - i + 1]) % MOD;
        }

        g[n + 1] = (rhs - known + MOD) % MOD * inv[n + 1] % MOD;
    }

    ll ans = 0;
    ll prefix = 0;

    for (int s = 0; s <= N; s++) {
        prefix += g[s];
        if (prefix >= MOD) prefix -= MOD;

        if (s % 9 == N % 9) {
            ans += prefix;
            ans %= MOD;
        }
    }

    ans = (ans - N / 9) % MOD;
    if (ans < 0) ans += MOD;

    cout << ans << '\n';
    return 0;
}
```

## ABC450 G - Random Subtraction

链接：https://atcoder.jp/contests/abc450/tasks/abc450_g

### 题意

给定 `N` 个非负整数。重复执行：随机选择两个不同下标 `i, j`，删除 `A_i, A_j`，并加入 `A_i - A_j`，直到只剩一个数。设最后剩下的数为 `x`，求：

```text
E[x^2] mod 998244353
```

### 思路

最后的 `x` 一定可以写成：

```text
x = c_1 A_1 + c_2 A_2 + ... + c_N A_N
```

其中每个 `c_i` 都是 `+1` 或 `-1`。

所以：

```text
E[x^2] = sum A_i^2 + 2 * sum_{i<j} E[c_i c_j] A_i A_j
```

由对称性，任意 `i != j` 的 `E[c_i c_j]` 相同。官方推导结果为：

- `N = 1`：交叉项系数为 `0`；
- `N = 2`：交叉项系数为 `-1`；
- `N >= 3`：交叉项系数为 `-2 / (3(N-1))`。

令：

```text
S = sum A_i
Q = sum A_i^2
```

因为 `S^2 - Q = 2 * sum_{i<j} A_i A_j`，所以答案为：

```text
Q + d * (S^2 - Q)
```

其中 `d = E[c_i c_j]`。

### 复杂度

时间复杂度：`O(N)`  
空间复杂度：`O(1)`

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 998244353;

long long mod_pow(long long a, long long e) {
    long long r = 1;
    while (e > 0) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

long long inv(long long x) {
    return mod_pow((x % MOD + MOD) % MOD, MOD - 2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;

    long long S = 0;
    long long Q = 0;

    for (int i = 0; i < N; i++) {
        long long a;
        cin >> a;
        a %= MOD;
        S = (S + a) % MOD;
        Q = (Q + a * a) % MOD;
    }

    long long d;
    if (N == 1) {
        d = 0;
    } else if (N == 2) {
        d = MOD - 1;
    } else {
        d = MOD - 2 * inv(3LL * (N - 1) % MOD) % MOD;
    }

    long long ans = (Q + d * ((S * S % MOD - Q + MOD) % MOD)) % MOD;
    cout << ans << '\n';
    return 0;
}
```
