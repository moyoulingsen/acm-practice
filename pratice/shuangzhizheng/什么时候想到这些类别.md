# 什么情况下想到用这些类别

## 1. 想到滑动窗口基础
当题目出现以下特征时优先考虑：
- 问连续子段 / 连续子串；
- 要求最长、最短、满足条件的一个区间；
- 区间右移后可以通过缩左端点维持合法性。

关键词：连续区间、最短/最长、覆盖、去重、满足条件后收缩。

## 2. 想到固定窗口与单调队列
当题目出现以下特征时优先考虑：
- 窗口长度固定为 k；
- 每次窗口向右平移一格；
- 需要快速求每个窗口的最大值、最小值。

关键词：固定长度窗口、区间最值、每次平移一格。

## 3. 想到排序后双指针
当题目出现以下特征时优先考虑：
- 元素顺序本身不重要，可以先排序；
- 排序后“越往右越大”的单调性有帮助；
- 要找满足差值、和、范围限制的一段元素。

关键词：排序、差值限制、范围限制、配对。

## 4. 想到计数型双指针
当题目出现以下特征时优先考虑：
- 不是只找一个区间，而是统计有多少个合法区间；
- 对某个左端点，合法右端点往往形成连续一段；
- 右指针可以只增不减。

关键词：统计区间个数、合法右端点成段出现、右指针不回退。

## 5. 想到前缀和与窗口
当题目出现以下特征时优先考虑：
- 题目和区间和有关；
- 直接枚举区间太慢；
- 可以先转成前缀和，再用窗口、单调性或最值维护优化。

关键词：区间和、前缀和、长度限制、最优子段。

## 总结
看到题目时可以按这个顺序想：
1. 是不是连续区间问题？
2. 能不能通过移动左右指针维护合法性？
3. 右指针能不能只增不减？
4. 是固定窗口、最值窗口，还是统计区间个数？
5. 如果和区间和有关，能不能先上前缀和？
