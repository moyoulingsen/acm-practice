# 双指针 / 滑动窗口题目类别

## 1. 滑动窗口基础
- 特征：连续区间，右端点扩张，满足条件后缩左端点。
- 典型题：P1638 逛画展。

## 2. 固定窗口与单调队列
- 特征：窗口长度固定，常维护窗口最大值 / 最小值。
- 典型题：P1886 滑动窗口。

## 3. 排序后双指针
- 特征：先排序，再利用区间单调性移动左右指针。
- 典型题：P3143 Diamond Collector S。

## 4. 计数型双指针
- 特征：对每个左端点或右端点，统计一批合法区间个数。
- 典型题：P6465 Starry Sky。

## 5. 前缀和与窗口
- 特征：先把区间和转成前缀和，再在窗口中维护最值或合法性。
- 典型题：P1714 切蛋糕。
