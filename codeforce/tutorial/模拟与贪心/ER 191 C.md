**题型**：模拟 / 贪心 / mex

**难度体感**：很适合用来训练“把答案拆成贡献”的感觉

你在 [codeforce/virtual race/ER 191/3.cpp](../../virtual%20race/ER%20191/3.cpp) 和 [codeforce/virtual race/ER 191/3.1.cpp](../../virtual%20race/ER%20191/3.1.cpp) 里，其实已经抓到了两个关键信号：

---

## 题意压缩

给定数组 `a`。

你需要根据题目定义，把答案写成一个关于：

- 数组最大值 `M`
- 整体 mex `G`

的公式。

这题本质不是暴力模拟删数，而是：

- 先看哪些值已经出现；
- 再讨论从 `0` 往上，第一个没出现的数是谁；
- 然后分情况累加贡献。

---

## 关键观察 1：先把全局 mex 求出来

设：

- `M = max(a)`
- `G = mex(a)`

那么 `0,1,2,...,G-1` 一定都出现过，`G` 没出现。

这会直接决定后面很多项怎么加。

你的原代码已经有这个动作：

- 用 `vis` 统计是否出现；
- 从 `0` 往上找第一个没出现的数。

这是完全正确的第一步。

---

## 关键观察 2：答案可以拆成三部分

这题最后答案可以整理成：

### 情况一：`M >= G`

\[
ans = n\cdot M + \frac{G(G+1)}{2} + (n-1-G)\cdot G
\]

### 情况二：`M < G`

\[
ans = n\cdot M + \frac{G(G+1)}{2} - M + (n-G)\cdot G
\]

这正是你后面那份代码里的最终式子。

所以这篇教程最重要的，不是重新记一遍代码，而是记住：

> **一旦题目把答案逼成“只和最大值、mex、长度有关”，就该尝试做整体分类讨论，而不是逐位模拟。**

---

## 怎么理解这个公式

虽然最后式子不长，但它不是拍脑袋出来的。

你可以把它理解成三层贡献：

### 第一层：最大值带来的基础贡献

\[
n\cdot M
\]

这一项来自“每个位置都先按最大值贡献一遍”的基底。

### 第二层：`0..G` 这段完整前缀的额外贡献

因为 `0..G-1` 都出现了，形成了一个完整前缀，所以会额外形成：

\[
\frac{G(G+1)}{2}
\]

这种前缀和式子的贡献。

### 第三层：根据 `M` 和 `G` 的大小关系修正

当 `M >= G` 和 `M < G` 时，后面的项个数不同，所以修正项也不同：

- `M >= G` 时是
  \[
  (n-1-G)\cdot G
  \]
- `M < G` 时是
  \[
  -M + (n-G)\cdot G
  \]

这就是为什么最后必须分两类写。

---

## 为什么 reverse 做法不对

在你最早一版 [codeforce/virtual race/ER 191/3.cpp](../../virtual%20race/ER%20191/3.cpp#L10-L33) 里，你把数组 reverse 之后尝试从后往前扫 mex。

这个思路的问题是：

- mex 取决于“值有没有出现”，不是取决于顺序；
- 这题真正关键是全局出现集合和最大值；
- 所以顺序信息基本不重要，reverse 不会帮你简化问题。

以后看到 mex 题，先问自己：

1. 是前缀 mex / 子数组 mex？
2. 还是只需要全局出现情况？

这题明显更偏第二类。

---

## 思路步骤

1. 读入数组。
2. 求最大值 `M`。
3. 用 `vis` 标记出现过的值。
4. 从 `0` 开始找整体 mex，记作 `G`。
5. 按 `M >= G` 还是 `M < G` 分情况套公式。
6. 输出答案。

---

## 易错点

### 1. `vis` 只开到 `n` 附近就够了

因为 mex 不会超过 `n`。

### 2. 别把 mex 和最大值混为一谈

`mex` 是“第一个没出现的非负整数”，`max` 是“出现过的最大值”，它们完全不是一个概念。

### 3. 分类讨论不能漏

`M >= G` 和 `M < G` 的公式不一样，不能偷懒合并。

### 4. 注意答案可能很大

要用 `long long`。

---

## 复杂度

- 扫一遍数组求 `M`：`O(n)`
- 扫一遍找 `mex`：`O(n)`

总复杂度：

\[
O(n)
\]

---

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;

        vector<int> a(n);
        int M = 0;
        vector<int> vis(n + 1, 0);

        for (int i = 0; i < n; ++i) {
            cin >> a[i];
            M = max(M, a[i]);
            if (a[i] <= n) vis[a[i]] = 1;
        }

        int G = 0;
        while (G <= n && vis[G]) G++;

        long long ans;
        if (M >= G) {
            ans = 1LL * n * M
                + 1LL * G * (G + 1) / 2
                + 1LL * (n - 1 - G) * G;
        } else {
            ans = 1LL * n * M
                + 1LL * G * (G + 1) / 2
                - M
                + 1LL * (n - G) * G;
        }

        cout << ans << '\n';
    }

    return 0;
}
```

## 一句话总结

这题的核心不是模拟，而是：**先求 `max` 和 `mex`，再把答案按两种大小关系直接拆成公式。**
