# CF 1101 B - Accordion

**题目链接**：<https://codeforces.com/problemset/problem/1101/B>

**题型**：字符串 / 贪心扫描

**难度体感**：B 题，关键是按顺序找出 `[:|:]` 的骨架。

---

## 题意压缩

在字符串中找一个子序列，形如：

\[
[ : \text{若干个 } | : ]
\]

也就是必须按顺序出现：

1. `[`
2. `:`
3. 中间若干 `|`
4. `:`
5. `]`

问最大长度。如果不存在，输出 `-1`。

---

## 关键观察

最外层必须尽量固定：

- 从左往右找第一个 `[`；
- 在它后面找第一个 `:`；
- 从右往左找第一个 `]`；
- 在它前面找第一个 `:`。

如果左边的 `:` 在右边的 `:` 前面，就可以统计中间的 `|` 数量。

答案为：

\[
4 + \text{中间 } | \text{ 的个数}
\]

---

## 思路步骤

1. 找 `l1 = '['` 的位置。
2. 找 `l2 = ':'`，且 `l2 > l1`。
3. 找 `r1 = ']'` 的位置，从右向左。
4. 找 `r2 = ':'`，且 `r2 < r1`。
5. 如果任意位置不存在，或 `l2 >= r2`，输出 `-1`。
6. 统计 `(l2,r2)` 之间 `|` 个数，答案为 `cnt+4`。

---

## 易错点

- 是子序列，不要求连续；
- 右边的 `:` 要从右侧往左找；
- 中间只统计 `|`，其他字符忽略。

---

## 复杂度

\[
O(n)
\]

---

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();

    int l1 = -1, l2 = -1, r1 = -1, r2 = -1;
    for (int i = 0; i < n; ++i) {
        if (s[i] == '[') {
            l1 = i;
            break;
        }
    }
    if (l1 != -1) {
        for (int i = l1 + 1; i < n; ++i) {
            if (s[i] == ':') {
                l2 = i;
                break;
            }
        }
    }
    for (int i = n - 1; i >= 0; --i) {
        if (s[i] == ']') {
            r1 = i;
            break;
        }
    }
    if (r1 != -1) {
        for (int i = r1 - 1; i >= 0; --i) {
            if (s[i] == ':') {
                r2 = i;
                break;
            }
        }
    }

    if (l1 == -1 || l2 == -1 || r1 == -1 || r2 == -1 || l2 >= r2) {
        cout << -1 << '\n';
        return 0;
    }

    int bars = 0;
    for (int i = l2 + 1; i < r2; ++i) {
        if (s[i] == '|') bars++;
    }

    cout << bars + 4 << '\n';
    return 0;
}
```

---

## 一句话总结

先从两边定住 `[:` 和 `:]`，中间有多少根 `|` 就加多少。
