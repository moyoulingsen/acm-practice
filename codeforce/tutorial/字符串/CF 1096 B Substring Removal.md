# CF 1096 B - Substring Removal

**题目链接**：<https://codeforces.com/problemset/problem/1096/B>

**题型**：组合计数 / 字符串

**难度体感**：B 题，关键在只看首尾连续段。

---

## 题意压缩

给定字符串 `s`。

你会删除一个非空子串，统计最终可能得到多少种不同结果。

答案对 `998244353` 取模。

---

## 关键观察

真正起作用的只有：

- 左边开头连续相同字符的长度
- 右边结尾连续相同字符的长度

设：

- 左边连续段长度为 `L`
- 右边连续段长度为 `R`

然后分两种情况：

### 情况 1：首字符和尾字符不同

答案是：

\[
L + R + 1
\]

### 情况 2：首字符和尾字符相同

答案是：

\[
(L+1)(R+1)
\]

---

## 为什么只看首尾

因为删除中间子串后，留下来的结果本质由“保留前缀多少”和“保留后缀多少”决定。

而能自由变化的部分，正是两端那段和首尾字符相同的连续块。

中间如果字符不同，它们的结构会把方案唯一锁住；
真正能组合出不同结果的，是两端这些连续可选长度。

---

## 思路步骤

1. 统计前缀连续相同字符长度 `L`
2. 统计后缀连续相同字符长度 `R`
3. 若 `s[0] == s[n-1]`，输出 `(L+1)(R+1)`
4. 否则输出 `L+R+1`

---

## 复杂度

\[
O(n)
\]

---

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

static const long long MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s;
    cin >> n >> s;

    long long L = 1, R = 1;
    while (L < n && s[L] == s[0]) L++;
    while (R < n && s[n - 1 - R] == s[n - 1]) R++;

    if (s[0] == s[n - 1]) {
        cout << ((L + 1) * (R + 1)) % MOD << '\n';
    } else {
        cout << (L + R + 1) % MOD << '\n';
    }
    return 0;
}
```

---

## 一句话总结

这题核心是：**只统计首尾连续段长度，再按首尾字符是否相同分类讨论。**
