# CF 1107 E - Fair and Square

**题目链接**：<https://codeforces.com/problemset/problem/1107/E>

**题型**：区间 DP / 消消乐型合并

**难度体感**：典型紫名题，重点在“相同字符延后合并”的状态设计。

---

## 题意压缩

给一个字符串，每次你可以删掉一段连续且字符相同的块，若这次删掉的块长度为 `k`，收益是 `a[k]`。

问：把整个串删空，最大收益是多少。

---

## 为什么这是经典区间 DP

如果收益只是线性的，那看到一段就删掉通常就够了。

但这里收益是任意给定的 `a[k]`，这意味着：

- 现在删掉一段长度为 `x` 的块，不一定最优；
- 可能应该先把中间别的字符删掉，
- 再把两个相同字符块拼起来一起删，收益更高。

所以这题的本质是：

> **同色块是否要立刻删除，还是要留到后面和别处合并。**

这正是区间 DP 最擅长处理的结构。

---

## 关键状态

设：

\[
dp(l,r,k)
\]

表示当前考虑区间 `[l,r]`，并且把 `s[r]` 这个字符右边额外接上了 `k` 个和它相同的字符时，这一段的最大收益。

也可以理解为：

- `s[r]` 不是单独一个点；
- 它实际上带着一个“尾巴”，这个尾巴里有 `k` 个和它相同的字符；
- 我们要决定是现在把它删掉，还是先把前面某些位置清空，再把相同字符并过来。

这是这类题的标准模型。

---

## 转移怎么想

### 1. 直接删掉最后这一组

如果不和前面合并，那就先把 `[l,r-1]` 处理好，然后把 `s[r]` 连同尾巴一起删掉：

\[
dp(l,r,k)=dp(l,r-1,0)+a[k+1]
\]

因为最后这一组长度是 `k+1`。

### 2. 把 `s[r]` 和前面某个相同字符合并

如果存在 `i` 满足：

- `l \le i < r`
- `s[i]=s[r]`

那么可以先把中间 `(i,r)` 之间的字符删空，让 `s[i]` 和 `s[r]` 连起来。

这时：

- `[i+1,r-1]` 必须先独立删光；
- `[l,i]` 这部分则把 `s[i]` 当作“尾巴长度又增加了 1”继续做。

于是有转移：

\[
dp(l,r,k)=\max\big(dp(l,r,k),\ dp(l,i,k+1)+dp(i+1,r-1,0)\big)
\]

这就是整题最核心的一步。

---

## 为什么一定要有第三维 `k`

如果只写 `dp[l][r]`，你根本不知道：

- 区间右端这个字符，现在到底是单独删；
- 还是已经和右边若干个同字符捆在一起了。

而这个信息会直接影响删掉它时得到的 `a[len]`。

所以第三维不是“优化项”，而是必需信息。

---

## 思路步骤

1. 读入字符串 `s` 和收益数组 `a[1..n]`。
2. 用记忆化搜索实现 `dfs(l,r,k)`。
3. 先做“直接删掉末尾组”的转移。
4. 再枚举区间里所有和 `s[r]` 相同的位置，尝试合并。
5. 输出 `dfs(0,n-1,0)`。

---

## 易错点

### 1. `k` 表示的是“额外接上的同字符个数”

不是整组长度。

真正删掉这一组时，长度是 `k+1`。

### 2. 合并时中间区间必须先删空

只有把 `[i+1,r-1]` 清空，`s[i]` 和 `s[r]` 才能贴在一起。

### 3. 记忆化搜索边界

- `l > r` 时返回 `0`
- `l == r` 时答案是 `a[k+1]`

---

## 复杂度

三维区间 DP，状态数约 `O(n^3)`，每个状态再枚举一个切分点，朴素实现常记作 `O(n^4)`。

在本题数据范围下，记忆化搜索版本是可过的。

---

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

static const long long INF = -(1LL << 60);

int n;
string s;
vector<long long> a;
long long dp[205][205][205];
bool vis[205][205][205];

long long dfs(int l, int r, int k) {
    if (l > r) return 0;
    if (vis[l][r][k]) return dp[l][r][k];
    vis[l][r][k] = true;

    long long &res = dp[l][r][k];
    res = dfs(l, r - 1, 0) + a[k + 1];

    for (int i = l; i < r; ++i) {
        if (s[i] == s[r]) {
            res = max(res, dfs(l, i, k + 1) + dfs(i + 1, r - 1, 0));
        }
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    cin >> s;
    a.assign(n + 1, 0);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    cout << dfs(0, n - 1, 0) << '\n';
    return 0;
}
```

---

## 一句话总结

这题就是：**区间 DP + 尾部同色块合并，核心状态是 `dp(l,r,k)`。**
