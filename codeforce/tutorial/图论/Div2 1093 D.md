# Div2 1093 D - Beautiful Graph

**题目链接**：<https://codeforces.com/contest/1093/problem/D>

**题型**：图论 / 二分图染色 / 计数

**难度体感**：紫名及以下应该会的二分图计数题

---

## 题意压缩

给一张无向图，你需要把每个点染成两种颜色之一，并满足：

- 每条边两端颜色不同。

如果做不到，答案是 `0`。

如果做得到，则对每个连通块统计一种特殊方案数，最后把所有连通块的贡献相乘。

---

## 第一层：先判断是不是二分图

只要题目要求“每条边两端颜色不同”，第一反应就应该是：

- 这是不是二分图判定？

做法很标准：

- 对每个还没访问的点做 BFS / DFS；
- 染成 `0/1` 两色；
- 如果遇到一条边两端颜色相同，说明不是二分图，直接输出 `0`。

---

## 第二层：为什么答案和 `2^{cnt0}+2^{cnt1}` 有关

设某个连通块被染成两部分：

- 左边有 `cnt0` 个点
- 右边有 `cnt1` 个点

这题的关键不是普通“二分图有 2 种染色法”而已，而是：

- 你可以把某一侧的点都选成一种角色；
- 也可以反过来选另一侧。

于是这个连通块的贡献就是：

\[
2^{cnt0}+2^{cnt1}
\]

直觉上可以这样记：

- 要么把左侧作为“主要集合”，它内部每个点各自有 2 种独立选择；
- 要么把右侧作为“主要集合”。

题目的标准答案最终就是把每个连通块的这个贡献连乘起来。

---

## 为什么单点连通块答案是 3 不是 2

这题最容易卡住的地方就在这里。

如果一个连通块只有 1 个点，那么：

- `cnt0=1`
- `cnt1=0`

贡献是：

\[
2^1+2^0=3
\]

不是 2。

所以千万不要把它想成“普通二分图染色只有 2 种”。

---

## 思路步骤

1. 预处理 `pow2[i]=2^i mod MOD`。
2. 建图。
3. 枚举每个点，如果未访问：
   - 从它开始 BFS / DFS；
   - 染色并统计这个连通块两边点数 `cnt0, cnt1`；
   - 若发现冲突，直接输出 `0`；
   - 否则把答案乘上 `pow2[cnt0] + pow2[cnt1]`。
4. 输出最终答案。

---

## 易错点

### 1. 忘记处理非连通图

答案不是只看一个连通块，而是所有连通块的贡献相乘。

### 2. 把贡献写成 2

这是最常见错误。这里不是问“有多少种合法二染色”，而是题目定义下的方案数。

正确是：

\[
2^{cnt0}+2^{cnt1}
\]

### 3. 单点连通块也要套公式

单点块不是特判成 2，而是照样套：

\[
2^1+2^0=3
\]

### 4. 模运算别漏

每个连通块乘进去之前就要先取模。

---

## 复杂度

设图有 `n` 个点，`m` 条边。

- 建图：`O(m)`
- BFS / DFS 染色：`O(n+m)`

总复杂度：

\[
O(n+m)
\]

---

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

static const int MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    const int MAXN = 300000;
    vector<int> pow2(MAXN + 1, 1);
    for (int i = 1; i <= MAXN; ++i) {
        pow2[i] = (pow2[i - 1] * 2LL) % MOD;
    }

    while (T--) {
        int n, m;
        cin >> n >> m;

        vector<vector<int>> g(n + 1);
        for (int i = 0; i < m; ++i) {
            int u, v;
            cin >> u >> v;
            g[u].push_back(v);
            g[v].push_back(u);
        }

        vector<int> color(n + 1, -1);
        long long ans = 1;
        bool ok = true;

        for (int s = 1; s <= n && ok; ++s) {
            if (color[s] != -1) continue;

            queue<int> q;
            q.push(s);
            color[s] = 0;
            int cnt[2] = {1, 0};

            while (!q.empty() && ok) {
                int u = q.front();
                q.pop();
                for (int v : g[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        cnt[color[v]]++;
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        ok = false;
                        break;
                    }
                }
            }

            if (!ok) break;
            ans = ans * ((pow2[cnt[0]] + pow2[cnt[1]]) % MOD) % MOD;
        }

        cout << (ok ? ans : 0) << '\n';
    }

    return 0;
}
```

---

## 一句话总结

这题就是：**先判二分图，再对每个连通块乘上 `2^{左边点数}+2^{右边点数}`。**
