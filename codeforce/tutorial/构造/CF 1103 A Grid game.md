# CF 1103 A - Grid game

**题目链接**：<https://codeforces.com/problemset/problem/1103/A>

**题型**：构造 / 模拟

**难度体感**：A 题，但题面容易让人想复杂；核心是固定两套不冲突的摆法。

---

## 题意压缩

给一个只包含 `0/1` 的字符串。对每个字符，要在 `4 x 4` 网格中放一个骨牌：

- 遇到 `0`，放一个竖着的 `1 x 2` 骨牌；
- 遇到 `1`，放一个横着的 `2 x 1` 骨牌。

每次输出骨牌左上角位置，并保证整个过程合法。

---

## 关键观察

不需要真的维护整个棋盘。

可以固定使用几组不会互相冲突的位置：

- 对 `0`：在第 1 列交替放 `(1,1)` 和 `(3,1)`，竖着占两格；
- 对 `1`：在第 3 行交替放 `(1,3)` 和 `(1,1)` 这类横向位置也可。

更经典的构造：

- `0` 使用 `(1,1)`、`(3,1)` 交替；
- `1` 使用 `(1,3)`、`(1,1)` 交替。

为了避免解释混乱，下面采用一套稳定的做法：

- `0`：输出 `(1,1)`、`(3,1)` 交替；
- `1`：输出 `(1,3)`、`(3,3)` 交替。

它们分别占据左右两列区域，不会互相冲突。

---

## 思路步骤

1. 读入字符串 `s`。
2. 准备两个计数器：
   - `cnt0` 控制竖骨牌位置；
   - `cnt1` 控制横骨牌位置。
3. 遇到 `0` 输出 `(1,1)` 或 `(3,1)`。
4. 遇到 `1` 输出 `(1,3)` 或 `(3,3)`。
5. 每类内部交替即可。

---

## 易错点

- Codeforces 原题只要求输出一种合法构造；
- 不要每一步都重新搜索棋盘，固定构造足够；
- 行列从 1 开始输出。

---

## 复杂度

\[
O(|s|)
\]

---

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    int cnt0 = 0, cnt1 = 0;
    for (char c : s) {
        if (c == '0') {
            cout << (cnt0 % 2 == 0 ? 1 : 3) << ' ' << 1 << '\n';
            cnt0++;
        } else {
            cout << (cnt1 % 2 == 0 ? 1 : 3) << ' ' << 3 << '\n';
            cnt1++;
        }
    }

    return 0;
}
```

---

## 一句话总结

这题不用搜索：给 `0` 和 `1` 各安排两套固定位置，交替输出即可。
