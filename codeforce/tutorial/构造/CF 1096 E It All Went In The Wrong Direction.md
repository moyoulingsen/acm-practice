# CF 1096 E - It All Went In The Wrong Direction

**题目链接**：<https://codeforces.com/problemset/problem/1096/E>

**题型**：构造 / 贪心 / 不变量

**难度体感**：中紫附近，重点在发现操作背后的不变量。

---

## 这类题怎么想

题面里只要出现“方向、翻转、交换、改变路径”之类操作，通常都要先找：

- 有哪些量会变；
- 有哪些量永远不变；
- 目标状态到底等价于什么条件。

很多时候你不是直接做题，而是在做：

> **把题面过程压成一个更简单的判定问题。**

---

## 通用复盘框架

1. 列出一次操作会影响哪些局部信息；
2. 寻找是否存在全局不变量；
3. 看最终目标能否改写成某种有序性 / 配平条件；
4. 再决定用贪心、构造还是 DP。

---

## 参考代码

下面给一份“不断修正逆序局部直到满足整体条件”的参考框架：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    string s;
    cin >> s;

    int ops = 0;
    for (int i = 0; i + 1 < n; ++i) {
        if (s[i] > s[i + 1]) {
            swap(s[i], s[i + 1]);
            ops++;
        }
    }

    cout << s << '\n';
    cout << ops << '\n';
    return 0;
}
```

> 这份代码不是原题的逐字实现，而是这种“操作修正 + 不变量观察”题型的参考模板。后续精修原题时，可以据此替换成贴题实现。

---

## 为什么值得补

这类题赛时很容易卡在“看懂题面但没抽象出来”。

而一旦你建立起“先找不变量”的习惯，很多 E 题就会明显顺手。

---

## 一句话总结

方向变化类题最重要的是：**别急着模拟，先找不变量，再把目标改写成简单条件。**
