# Div1+2 1110 B - Tape

**题目链接**：<https://codeforces.com/contest/1110/problem/B>

**题型**：构造 / 贪心

**难度体感**：紫名及以下应掌握的经典贪心模型

---

## 题意压缩

给你若干已经被标记的位置，要求用 `k` 段 tape 覆盖所有这些位置。

每段 tape 覆盖的是一段连续区间，总代价等于所有 tape 覆盖长度之和。

问：怎样分成 `k` 段，才能让总覆盖长度最小？

---

## 关键观察

如果只能用 **1 段**，那最优显然是：

- 从最左边被标记的位置一直覆盖到最右边被标记的位置。

这样总代价是：

\[
a_m-a_1+1
\]

其中 `a_1<a_2<...<a_m` 是所有被标记位置。

现在允许用 `k` 段，本质上就是：

- 先把整个大区间全盖住；
- 然后在若干个“相邻标记点之间的空隙”处剪开。

每剪开一次，就少覆盖一段空白区域。

所以问题变成：

> 在所有相邻点之间的空隙里，选出 `k-1` 个最大的空隙不覆盖。

---

## 为什么只看相邻间隔

设已排序后的位置是：

\[
a_1<a_2<...<a_m
\]

如果我们不切开，那答案是：

\[
a_m-a_1+1
\]

而相邻两点 `a_i, a_{i+1}` 之间如果有空白，那么空白长度是：

\[
a_{i+1}-a_i-1
\]

如果在这里断开，我们就不用覆盖这段空白，因此总答案会减少这部分长度。

所以贪心地选择最大的 `k-1` 个空白即可。

---

## 思路步骤

1. 读入所有标记位置 `a`。
2. 如果 `k >= m`，那么每个点单独一段，答案就是 `m`。
3. 否则：
   - 先算整段覆盖长度 `a[m-1]-a[0]+1`；
   - 计算每个相邻间隔的“可节省长度” `a[i]-a[i-1]-1`；
   - 把这些节省量从大到小排序；
   - 减去最大的 `k-1` 个即可。

---

## 易错点

### 1. 减去的是空白长度，不是相邻差值

很多人会直接减 `a[i]-a[i-1]`，这是错的。

因为两端标记点本身还是要被覆盖的，真正省掉的是中间空白：

\[
a_i-a_{i-1}-1
\]

### 2. `k >= m` 的时候答案不是 `1`

这时每个标记点都可以自己开一段，每段长度都是 `1`，所以答案是 `m`。

### 3. 这题不需要复杂 DP

看到“分成 k 段”很容易往区间 DP 想，但这里代价函数非常特殊：

- 切开能省多少，只取决于切口本身；
- 各个切口之间互不影响。

所以直接贪心选最大的空隙即可。

---

## 复杂度

设被标记的位置数为 `m`。

- 计算间隔：`O(m)`
- 排序间隔：`O(m log m)`

总复杂度：

\[
O(m\log m)
\]

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;

    vector<int> a(m);
    for (int i = 0; i < m; ++i) cin >> a[i];

    if (k >= m) {
        cout << m << '\n';
        return 0;
    }

    vector<int> gap;
    for (int i = 1; i < m; ++i) {
        gap.push_back(a[i] - a[i - 1] - 1);
    }

    sort(gap.begin(), gap.end(), greater<int>());

    int ans = a.back() - a.front() + 1;
    for (int i = 0; i < k - 1; ++i) {
        ans -= gap[i];
    }

    cout << ans << '\n';
    return 0;
}
```

---

## 一句话总结

这题本质是：**先把整段全覆盖，再贪心地在最大的 `k-1` 个空白处断开。**
