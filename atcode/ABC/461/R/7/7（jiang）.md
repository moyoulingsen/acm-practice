# 7（jiang）.cpp 的思路

这份代码的核心思路其实就是把原问题转成 **二分图最大匹配**。

最后答案写成：

`2026 * N - 1013 * 最大匹配`

这和我前面说的

`1013 * (2N - 最大匹配)`

是完全一样的，因为：

`2026N - 1013*mat = 1013*(2N-mat)`

---

## 1. 原问题怎么转

原题要求给每个点一个 `0..2026` 的非负整数权值 `W_i`，满足：

- 对每条边 `(u,v)`，都有 `W_u + W_v <= 2026`

目标是最大化：

`sum W_i`

这份代码采用的结论是：

> 答案等于 `1013 × 某个二分图的最大独立集大小`

而二分图最大独立集又等于：

> `点数总数 - 最大匹配`

由于这里构造出的二分图有 `2N` 个点，所以：

`ans = 1013 * (2N - max_matching)`

---

## 2. 二分图怎么建

把每个原图顶点 `i` 拆成两个点：

- 左部一个点 `i`
- 右部一个点 `N+i`

于是总共有：

- 左边 `1...N`
- 右边 `N+1...2N`

对于原图中的每条边 `(u,v)`，连两条二分图边：

- `u -> N+v`
- `v -> N+u`

这正对应官方题解里的：

- `A_u - B_v`
- `A_v - B_u`

代码里就是：

```cpp
 dc.je(u,N+v,1);
 dc.je(v,N+u,1);
```

---

## 3. 为什么还要加源点和汇点

因为代码是用 **Dinic 最大流** 来做二分图最大匹配。

所以会额外建立：

- 源点 `S = 0`
- 汇点 `T = 2N + 1`

然后：

- `S -> 左部每个点`，容量 `1`
- `右部每个点 -> T`，容量 `1`
- 左部到右部的原始边容量也都是 `1`

这样跑出来的最大流，就是这个二分图的最大匹配数。

对应代码：

```cpp
for(int i=1;i<=N;++i)
{
    dc.je(S,i,1);
    dc.je(N+i,T,1);
}
```

---

## 4. Dinic 这部分在干嘛

结构体 `dn` 是一个标准 Dinic 模板。

### `je`
加边函数，同时加入正向边和反向边。

### `ss`
BFS 分层，求层次图。

### `sd`
DFS 增广，在层次图里找增广路。

### `mf`
不断 BFS + DFS，直到无法增广，得到最大流。

所以：

```cpp
int bs=dc.mf(S,T);
```

这里的 `bs` 就是 **最大匹配数**。

---

## 5. 最后答案为什么这么写

代码最后是：

```cpp
long long da=2026LL*N-1013LL*bs;
cout<<da<<"\n";
```

其中：

- `bs = 最大匹配`
- 二分图总点数是 `2N`
- 最大独立集大小 = `2N - bs`

所以：

`ans = 1013 * (2N - bs)`

展开就是：

`ans = 2026N - 1013bs`

这就是代码里的式子。

---

## 6. 你可以怎么理解这个式子

可以把每个原图点想成最多能拿到两个 `1013`：

- 拿 0 份：权值 `0`
- 拿 1 份：权值 `1013`
- 拿 2 份：权值 `2026`

而原图边会制造冲突，使某些“1013 单位”不能同时取。

于是问题就变成：

> 在冲突图里最多能选多少个不冲突的 `1013` 单位。

这正是最大独立集。

二分图里：

- 总共有 `2N` 个这种“单位”
- 每出现一个匹配，等价于会减少一个独立集可取数量

因此答案就是：

`1013 × (2N - 最大匹配)`

---

## 7. 代码流程总结

这份代码的流程非常直接：

1. 读入 `N, M`
2. 建立网络流图
3. 源点连左部所有点，右部所有点连汇点
4. 对每条原图边 `(u,v)`，连 `u -> N+v` 和 `v -> N+u`
5. 跑 Dinic 求最大流 `bs`
6. 输出 `2026*N - 1013*bs`

---

## 8. 复杂度

图的规模：

- 点数 `O(N)`
- 边数 `O(N+M)`

Dinic 在这种二分图匹配场景下一般足够通过。

如果直接写 Hopcroft-Karp，也可以做，复杂度通常写作：

`O(M * sqrt(N))`

---

## 9. 一句话概括这份代码

> 先把原图转成一个 `2N` 个点的二分图，再用最大流求最大匹配，最后利用“二分图最大独立集 = 总点数 - 最大匹配”，得到答案 `2026N - 1013 * max_matching`。
