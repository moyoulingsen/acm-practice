# 这份题解在说什么

先把原题翻译成更容易想的形式：

- 每个点要赋一个整数权值 `W_i`，范围是 `0..2026`。
- 每条边 `(u,v)` 都要满足 `W_u + W_v <= 2026`。
- 目标是让所有点权总和最大。

官方题解本质上是在说明：

> **最优答案 = `1013 × 某个二分图的最大独立集大小`**。

然后因为二分图最大独立集可以转成最小点覆盖，再转成最大匹配/最大流，所以这题就做完了。

---

## 一、为什么会冒出 1013？

因为限制是

`W_u + W_v <= 2026`

而 `2026 = 2 × 1013`。

这暗示一个很自然的想法：

- 如果一个点取 `0`
- 或取 `1013`
- 或取 `2026`

那么边的限制会变得非常整齐。

后面官方第二种证明会说明：**一定存在一个最优解，使得所有点权只会取 `0, 1013, 2026` 这三种值。**

所以这题实际上是在做一个“`0/1/2` 赋值问题”，只不过最后再乘回 `1013`。

---

## 二、第一种做法：构造一个二分图

官方先构造一个新图：

- 左边放 `A_1, A_2, ..., A_N`
- 右边放 `B_1, B_2, ..., B_N`

一共 `2N` 个点，是个二分图。

对于原图中的每条边 `(u,v)`，在新图里连两条边：

- `A_u — B_v`
- `A_v — B_u`

也就是说，原图每条无向边，会在新图中“对称地”变成两条跨左右部的边。

---

## 三、为什么最大独立集会对应答案？

设这个二分图里取了一个最大独立集 `MIS`。

定义：

- `f(A_i)=1` 表示 `A_i` 被选进独立集，否则为 `0`
- `f(B_i)=1` 表示 `B_i` 被选进独立集，否则为 `0`

然后把原图中点 `i` 的权值设成：

`W_i = 1013 × (f(A_i) + f(B_i))`

于是每个点 `i` 有三种可能：

- 两边都没选：`W_i = 0`
- 只选了一个：`W_i = 1013`
- 两边都选了：`W_i = 2026`

这就正好对应 `0/1013/2026`。

### 为什么这样一定合法？

因为若原图有边 `(u,v)`，则新图里有边：

- `A_u — B_v`
- `A_v — B_u`

而独立集的性质是：**一条边的两个端点不能同时被选。**

所以：

- `f(A_u) + f(B_v) <= 1`
- `f(A_v) + f(B_u) <= 1`

两式相加：

`f(A_u)+f(B_u)+f(A_v)+f(B_v) <= 2`

再乘上 `1013`，就得到：

`W_u + W_v <= 2026`

所以这一定是个合法赋值。

并且总和是：

`ΣW_i = 1013 × Σ(f(A_i)+f(B_i)) = 1013 × |MIS|`

所以：

> **答案至少是 `1013 × |MIS|`**。

---

## 四、为什么答案不会超过这个值？

这部分是官方题解最跳的一步。

它说：把构造出来的二分图中的孤立点拿出来，剩下部分取一个最小边覆盖 `MEC`。

然后利用二分图性质：

`|MIS| = |MEC| + K`

其中 `K` 是孤立点个数。

这句话背后其实是经典结论链：

- 二分图中：`最大独立集 = 总点数 - 最小点覆盖`
- `最小边覆盖 = 非孤立点数 - 最大匹配`
- 对二分图这里整理后可得到上面的关系

你比赛里不一定要从“边覆盖”这个角度记；记住官方是想用一批边和孤立点，把所有 `A_i,B_i` 都“控制住”。

### 上界怎么数？

对于任意合法解 `W`：

- 每条 `MEC` 里的边 `(x,y)`，对应原图中的某条约束，所以有 `W_x + W_y <= 2026`
- 每个孤立点单独拿出来，显然其对应的权值也不超过 `2026`

于是把所有这些量加起来，可以覆盖 `2 × ΣW_i`，从而推出：

`2 × ΣW_i <= 2026 × (|MEC| + K) = 2026 × |MIS|`

所以：

`ΣW_i <= 1013 × |MIS|`

结合前面的下界，得到：

> **最优答案 = `1013 × |MIS|`**。

---

## 五、这个构造到底直观在哪？

你可以把：

- `A_i` 被选，理解成点 `i` 贡献了“前一半” `1013`
- `B_i` 被选，理解成点 `i` 贡献了“后一半” `1013`

于是点 `i` 最多贡献两半，也就是 `2026`。

而原图中一条边 `(u,v)` 的限制 `W_u + W_v <= 2026`，就等价于说：

> 点 `u` 和点 `v` 的四个“半份贡献”里，不能同时出现冲突的两半。

这个冲突关系，正好就由新图里的边表达出来；
而“选一些互不冲突的半份贡献，使总贡献最大”，就是最大独立集。

所以这个建图并不是拍脑袋，而是在把“每个点最多拿两半、相邻点之间有冲突”编码成独立集问题。

---

## 六、第二种做法在说什么？

第二种是更偏理论的解释：

### 1. 先把整数限制放宽成实数

也就是先允许 `W_i` 取任意实数，只要 `0 <= W_i <= 2026`，并满足边约束。

然后在所有最优解里，再选一个“不是 1013 整倍数的点尽量少”的解。

定义：

- `P_- = {v | 0 < W_v < 1013}`
- `P_+ = {v | 1013 < W_v < 2026}`

也就是：

- `P_-` 里是“卡在下半段中间”的点
- `P_+` 里是“卡在上半段中间”的点

### 2. 做一个微调

如果存在这两类点，就取一个很小的 `d`，把：

- `P_-` 里的每个点都 `+d`
- `P_+` 里的每个点都 `-d`

这样做不会破坏边约束，而且可以分析出：

- 如果 `|P_-| != |P_+|`，总和还能变大，和“已经最优”矛盾
- 如果 `|P_-| = |P_+|`，那总和不变，但可以让更多点碰到边界 `1013`，从而让“中间态点”的数量减少，和“已经最少”矛盾

所以中间态根本不可能存在。

于是可知：

> **一定存在最优解，使每个 `W_v` 都只能取 `0,1013,2026`。**

这就叫一种 **half-integrality（半整数性）** 现象。

---

## 七、把它缩成 0/1/2 之后是什么问题？

令：

`w_v = W_v / 1013`

则 `w_v ∈ {0,1,2}`，而边约束变成：

`w_u + w_v <= 2`

目标变成最大化 `Σw_v`。

这等价于一个有限状态优化问题：

- 给每个点选 `0/1/2`
- 但相邻两点不能凑出 `3` 或 `4`

也就是以下组合不允许：

- `(1,2)`
- `(2,1)`
- `(2,2)`

官方说这可以视为一个**子模函数最小化**，最终可转成最小割。

这条路线更像“理论证明 + 网络流建模”，而第一种路线更像“直接观察出建图”。

---

## 八、真正做题时应该记什么？

你最该记的是第一种构造，因为最直接。

### 结论

构造二分图：

- 点集：`A_1..A_N, B_1..B_N`
- 对原图每条边 `(u,v)`，连：`A_u-B_v` 和 `A_v-B_u`

则答案为：

`1013 × (这个二分图的最大独立集大小)`

而二分图最大独立集 = 总点数 - 最小点覆盖。

又由 König 定理：

- 最小点覆盖大小 = 最大匹配大小

所以若最大匹配大小为 `mat`，则

`MIS = 2N - mat`

因此最终答案：

`1013 × (2N - mat)`

---

## 九、复杂度

新图有：

- `2N` 个点
- `2M` 条边

跑二分图最大匹配（Hopcroft–Karp）复杂度通常是：

`O(E sqrt(V)) = O(M sqrt(N))`

官方写最大流也可以做。

---

## 十、一句话总结

这题的本质是：

> 把每个点的权值拆成两个 `1013`，然后把“相邻点不能同时拿冲突份额”的关系建成二分图，最后转成二分图最大独立集。

所以答案就是：

> **`1013 × (2N - 二分图最大匹配)`**

---

## 十一、如果你要写代码，核心步骤就是

1. 建二分图左右两侧各 `N` 个点。
2. 原图每条边 `(u,v)` 连 `u -> v` 和 `v -> u`（看作左到右的边）。
3. 求这个二分图的最大匹配数 `mat`。
4. 输出 `1013 * (2N - mat)`。

---

## 十二、给你的直白版翻译

“他在说什么” 的最直白版本就是：

- 这题虽然看起来是在给点赋 `0..2026` 的整数，
- 但其实最优解只需要考虑 `0, 1013, 2026` 三种值；
- 把每个点看成左右两个“1013 单位”；
- 原图里一条边会制造一些“这两个单位不能同时选”的冲突；
- 把所有冲突关系建成一个二分图；
- 最多能选多少个这样的“1013 单位”，就是这个二分图的最大独立集；
- 而二分图最大独立集 = 总点数 `2N` - 最大匹配；
- 所以最终答案就是 `1013 × (2N - 最大匹配)`。
