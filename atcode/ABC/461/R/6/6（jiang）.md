# 6（jiang）.cpp 思路说明

这份代码的核心想法是：

> 不直接按“序列”去做，而是先统计“从 `N` 的约数中选出若干个互不相同的数，使它们的乘积等于 `N`”的所有集合方案；
> 然后再乘上排列数，把集合还原成序列。

它和题解本质一致，只是实现上把三维 DP 压成了“按约数做 0/1 转移”的形式。

---

## 一、先做质因数分解，再枚举所有约数

代码开头先把 `n` 质因数分解：

```cpp
vector<long long> p;
vector<int> e;
```

其中：

- `p[i]` 表示第 `i` 个质因子；
- `e[i]` 表示对应指数。

随后用 DFS 枚举 `n` 的所有约数，放进数组 `d`：

```cpp
vector<long long> d;
function<void(int,long long)> f=[&](int i,long long v){ ... };
```

排序后，`d` 中保存了从小到大的全部约数。

这样做的原因是：

- 一个合法序列中的每个元素都必须整除 `N`；
- 所以候选元素只可能来自 `N` 的约数集合。

---

## 二、给每个约数编号

```cpp
unordered_map<long long,int> id;
for(int i=0;i<s;++i) id[d[i]]=i;
```

这里 `id[x]` 表示约数 `x` 在数组 `d` 中的位置。

作用是为了后面能快速从“约数值”找到“状态编号”。

---

## 三、长度上界 `l`

```cpp
int k=0;
for(int c:e) k+=c;
int l=k+1;
```

这里：

- `k` 是 `N` 的质因数总指数和；
- `l = k + 1` 作为可选元素个数的上界。

原因可以这样理解：

- 除了 `1` 以外，每选一个大于 `1` 的约数，都会消耗掉至少一个质因子；
- 所以选出的数个数不可能无限大；
- 再考虑 `1` 也最多只能选一次，因此可以用 `sum(e) + 1` 作为一个安全上界。

---

## 四、预处理转移边 `g`

```cpp
vector<vector<pair<int,int>>> g(s);
for(int i=0;i<s;++i){
    long long vi=d[i];
    long long rn=n/vi;
    for(int j=0;j<s;++j){
        long long vj=d[j];
        if(vj>rn) break;
        if(rn%vj==0){
            long long w=vj*vi;
            int to=id[w];
            g[i].emplace_back(j,to);
        }
    }
}
```

这段是整份代码最关键、也最绕的地方。

它在预处理这样一种关系：

> 若当前已经选出的一些数的乘积为 `d[j]`，再加入一个新的约数 `d[i]`，并且 `d[j] * d[i]` 仍然整除 `n`，那么新乘积就会变成 `d[to] = d[j] * d[i]`。

因此：

- `j` 表示旧乘积状态；
- `to` 表示加入 `d[i]` 后的新乘积状态。

`g[i]` 里存的其实就是：

> “把约数 `d[i]` 当成这一步新加入的元素时，它能从哪些乘积状态转移到哪些新状态。”

---

## 五、DP 数组含义

```cpp
vector<vector<long long>> c(s,vector<long long>(l+1,0));
vector<vector<long long>> h(s,vector<long long>(l+1,0));
c[0][0]=1;
```

这里定义：

- `c[x][L]`：选出 `L` 个**互不相同**的约数，且它们的乘积为 `d[x]` 的方案数；
- `h[x][L]`：所有这些方案的元素和总和。

由于 `d[0] = 1`，所以：

```cpp
c[0][0] = 1;
```

表示：

- 选 0 个数；
- 乘积为 1；
- 这种“空集合”方案有 1 种。

这就是 DP 的起点。

---

## 六、状态转移

```cpp
for(int i=0;i<s;++i){
    long long vm=d[i]%M;
    const auto& list=g[i];
    for(int L=l-1;L>=0;--L){
        for(auto& pr:list){
            int r=pr.first;
            int to=pr.second;
            long long cnt=c[r][L];
            if(cnt==0) continue;
            long long sum=h[r][L];
            c[to][L+1]=(c[to][L+1]+cnt)%M;
            h[to][L+1]=(h[to][L+1]+sum+cnt*vm)%M;
        }
    }
}
```

这部分表示：

- 当前枚举“准备加入”的新约数 `d[i]`；
- 如果之前有一些方案，它们选了 `L` 个数、乘积为 `d[r]`；
- 那么加入 `d[i]` 后，新方案的：
  - 元素个数变成 `L+1`；
  - 乘积变成 `d[to] = d[r] * d[i]`。

于是有：

### 1. 方案数转移

```cpp
c[to][L+1] += c[r][L]
```

### 2. 分数和转移

新方案的元素和 = 旧方案的元素和 + 新加入的 `d[i]`。

因此：

```cpp
h[to][L+1] += h[r][L] + c[r][L] * d[i]
```

这和标准题解中维护：

- 方案数 `dp0`
- 分数和 `dp1`

是完全一致的，只是写法更压缩。

## 七、为什么要倒序枚举 `L`

```cpp
for(int L=l-1;L>=0;--L)
```

这是一种典型的 0/1 背包写法。

原因是：

> 每个约数 `d[i]` 最多只能选一次。

如果正序更新，那么同一轮里刚刚加入的 `d[i]` 可能又被再次使用，导致重复选择同一个元素。

倒序更新就可以保证：

- 当前这轮的 `d[i]` 只会被加入一次；
- 从而确保选出来的元素互不相同。

---

## 八、最后为什么乘阶乘

```cpp
vector<long long> fac(l+1);
fac[0]=1;
for(int i=1;i<=l;++i) fac[i]=fac[i-1]*i%M;

long long ans=0;
int tg=s-1;
for(int L=1;L<=l;++L) ans=(ans+fac[L]*h[tg][L])%M;
```

这里：

- `tg = s - 1`，因为排完序后 `d[s-1] = n`；
- `h[tg][L]` 表示：
  - 选出 `L` 个不同约数；
  - 它们乘积为 `n`；
  - 这些集合方案的元素和总和。

但题目要求的是**序列**。

一个大小为 `L` 的集合，能形成：

`L!`

种不同排列，并且每种排列的元素和相同。

所以最终答案要累加：

```cpp
fac[L] * h[tg][L]
```

---

## 九、整份代码的本质

这份 `6（jiang）.cpp` 的思路可以概括为：

1. 先枚举 `N` 的所有约数；
2. 把问题转成：从这些约数中选若干个互不相同的数，使乘积等于 `N`；
3. 用二维 DP 维护：
   - 当前乘积是哪一个约数；
   - 当前选了多少个数；
4. 同时维护：
   - 方案数 `c`；
   - 分数和 `h`；
5. 最后乘上 `L!`，把“集合答案”恢复为“序列答案”。

---

## 十、一句话总结

这份代码其实是在做一个“按约数选或不选”的 0/1 背包式 DP：

> 状态记录“当前乘积”和“当前长度”，转移时加入一个新的约数，并同步更新方案数与分数和，最后再乘排列数得到题目答案。
