# A - Two Arithmetic Progressions 题目

- 原题链接：https://atcoder.jp/contests/arc221/tasks/arc221_a
- 题目名称：Two Arithmetic Progressions
- 时限：2 sec
- 内存限制：1024 MiB
- 分值：600

## 题意

给定正整数 `N, A, B, C, D`。

要求计算：

\[
\sum_{i=1}^{N} \gcd(Ai+B,\;Ci+D)
\]

并将答案对 `998244353` 取模。

其中 `gcd(x, y)` 表示 `x` 与 `y` 的最大公约数。

共有 `T` 组测试数据，需要对每组分别求解。

## 输入格式

```text
T
case_1
case_2
...
case_T
```

每组测试数据格式为：

```text
N A B C D
```

## 输出格式

对于每组测试数据，输出一行答案。

## 数据范围

- `1 <= T <= 200`
- `1 <= N <= 10^9`
- `1 <= A, B, C, D <= 10^4`
- 所有输入均为整数。

## 样例输入

```text
3
4 1 3 4 2
100000000 1 1 1 2
100000000 1 1 1 1
```

## 样例输出

```text
10
100000000
822404071
```

## 样例解释

第一组数据中：

\[
\gcd(4,6)+\gcd(5,10)+\gcd(6,14)+\gcd(7,18)=2+5+2+1=10
\]
