# B - Two-Powered Sum 题目

- 原题链接：https://atcoder.jp/contests/arc221/tasks/arc221_b
- 题目名称：Two-Powered Sum
- 时限：2 sec
- 内存限制：1024 MiB
- 分值：800

## 题意

给定正整数 `N` 和质数 `P`。

初始时有一个长度为 `N` 的序列：

\[
A=(A_1,A_2,\dots,A_N)
\]

且所有元素初始都为 `0`。

你可以进行任意次操作（也可以一次都不做）：

1. 选择一个非空子集 `S ⊆ {1,2,...,N}`；
2. 令

\[
x = \sum_{i\in S}2^{i-1}
\]

3. 对每个 `i ∈ S`，把 `A_i` 替换为 `x`。

问：最终可能得到多少种不同的序列 `A`，答案对 `P` 取模。

## 输入格式

```text
N P
```

## 输出格式

输出一个整数，表示答案。

## 数据范围

- `1 <= N <= 700`
- `P` 是质数，且 `10^8 < P < 10^9`
- 所有输入均为整数。

## 样例输入 1

```text
1 998244353
```

## 样例输出 1

```text
2
```

可能的序列为：`(0)`、`(1)`。

## 样例输入 2

```text
2 998244353
```

## 样例输出 2

```text
7
```

可能的序列为：

- `(0,0)`
- `(0,2)`
- `(1,0)`
- `(1,2)`
- `(1,3)`
- `(3,2)`
- `(3,3)`

## 其余样例

```text
输入：3 998244353
输出：57

输入：4 998244353
输出：1208

输入：77 777777773
输出：381787647
```
